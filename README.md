# Digital Clock

A simple digital clock built using Python’s `tkinter` GUI toolkit.  
The clock updates every second and displays the current time in **HH:MM:SS AM/PM** format.


## What This App Does

This project creates a clean, minimal digital clock window that:

- Shows the current time
- Updates automatically every second
- Uses a bold, high‑contrast design (white text on black background)
- Runs in a simple Tkinter window

##  Features

- **Live time display** (hours, minutes, seconds)
- **12‑hour format with AM/PM**
- **Automatic updates every 1000 ms**
- **Modern, minimal UI**
- **Lightweight — no external libraries needed**
